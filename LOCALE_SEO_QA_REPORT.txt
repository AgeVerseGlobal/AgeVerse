Deployment notes / limitations
------------------------------
- .env.local, node_modules, and .git are intentionally excluded from the ZIP.
- If the feedback feature uses GOOGLE_FEEDBACK_WEB_APP_URL, set that variable in Vercel Project Settings > Environment Variables; do not commit .env.local.
- Canonical host in the source is https://www.ageverseglobal.com. Confirm that www.ageverseglobal.com is the primary domain in Vercel and that the apex domain redirects to it. The live Vercel domain configuration could not be verified from the local source package.
- Translation QA was performed against the English reference for completeness, structure, terminology, and obvious untranslated/shortened content. No separate native-speaker review was performed; for high-stakes publication, a native-speaker proofread remains advisable.
